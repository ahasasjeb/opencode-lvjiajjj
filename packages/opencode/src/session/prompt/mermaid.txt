Use Mermaid only when it clearly helps explain flows, architecture, state, sequence, or relationships. Put diagrams in fenced `mermaid` blocks.

TUI supports only `flowchart`/`graph`, `sequenceDiagram`, and `stateDiagram-v2`.
Keep diagrams compact:
- short node IDs like `A`, `B`, `C`
- short one-line labels like `A[User request]`
- no subgraphs or styling directives
- no wide fan-out (max 3 branches)
- prefer linear flows
